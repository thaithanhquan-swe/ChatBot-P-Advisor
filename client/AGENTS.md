## UI/UX Design Guidelines

When creating or modifying frontend UI, design production-ready interfaces,
not design showcase concepts.

### Design Style

- Modern, clean, professional, minimal
- Practical educational web application
- Prioritize usability over decoration
- Use strong and clear visual hierarchy
- Keep spacing and alignment consistent
- Use familiar and conventional UI patterns
- Maintain consistency across all pages

### Visual System

- Primary color: PTIT red
- Background: white or subtle neutral gray
- Use neutral and subtle borders
- Use shadows only when necessary
- Use consistent border radius around 6–10px
- Maintain clear typography hierarchy
- Use comfortable but not excessive spacing

### Avoid AI-Generated Looking UI

Do NOT:

- Use excessive gradients
- Use glowing effects
- Use glassmorphism
- Use oversized headings unnecessarily
- Put every section inside a floating card
- Create unnecessary card-inside-card layouts
- Add icons beside every label
- Use excessive shadows
- Add decorative charts or statistics without a real purpose
- Add unnecessary badges or pills
- Use excessive empty space
- Create overly polished Dribbble-style layouts
- Add fake marketing content
- Add decorative elements without functional purpose

Every visual element should have a functional reason to exist.

### Product Context

This project is a PTIT Admission Chatbot system used by:

- Students
- Parents
- Admission advisors
- Administrators

The interface should feel trustworthy, straightforward, professional,
and slightly formal while remaining friendly to students.

Public pages should resemble a modern educational institution website,
not a startup landing page.

Admin and advisor pages should resemble real internal management software:
clear page titles, practical filters, readable tables, simple forms,
predictable actions, and restrained visual decoration.

### Implementation

When implementing a design:

- Prefer existing project components before creating new ones
- Reuse existing colors, typography, spacing, buttons, forms, and cards
- Do not introduce a new visual style for an individual page
- Keep responsive behavior practical
- Avoid unnecessary animations
- Use animations only when they improve interaction feedback
- Keep forms straightforward and easy to scan
- Keep management tables dense enough to be useful without feeling crowded

The final result should look like a real production application that
developers can maintain, not an AI-generated UI concept.

Design a production UI, not a design showcase.
